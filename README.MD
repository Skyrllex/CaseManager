# ⚖️ CaseManager

Локальный менеджер судебных дел для юриста / адвоката.
Все данные хранятся только на вашем компьютере, метаданные дел — зашифрованы (AES-GCM + PBKDF2).

- 📁 Каждое дело — отдельная папка с материалами
- 🔐 Шифрование метаданных мастер-паролем
- 👥 Участники (истец / ответчик / третье лицо / судья / …)
- 📎 Материалы дела: документы, фото, видео, аудио, произвольные файлы
- 🗂 Группы документов («Блок 1», «Приложения», «Переписка», …)
- 🔍 Фильтры по типу дела, стадии, типу и группе документа
- 🖥 Кроссплатформенно (Windows / Linux / macOS), Avalonia 11 + .NET 9

## Быстрый старт

### Требования

- Windows 10/11, Linux (X11/Wayland) или macOS 12+
- [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)
- Visual Studio 2022 (17.12+) или JetBrains Rider или VS Code + C# Dev Kit

### Установка
'''bash
git clone <your-repo-url> CaseManager
cd CaseManager
dotnet restore
dotnet build
'''
### Запуск
'''bash
dotnet run --project CaseManager.Desktop
'''
Или из Visual Studio: открыть CaseManager.sln, выбрать Set as Startup Project → CaseManager.Desktop, нажать F5.

При первом запуске появится окно ввода мастер-пароля — запомните его, восстановить доступ к делам без него невозможно.

## Как пользоваться

### 1. Вход

При первом запуске задаётся мастер-пароль. Все метаданные дел шифруются им. Пароль не хранится нигде, кроме вашей памяти.

> ⚠️ Запишите пароль. Если забудете — данные не восстановить (это осознанная плата за безопасность).

### 2. Главное окно
┌─────────────────────────────────────────────────────────────┐
│ [+ Новое дело] [✎ Редактировать] [📎 Добавить] [🗑 Удалить]  │
├─────────────────────┬───────────────────────────────────────┤
│ Все дела ▾          │  Название дела                        │
│ ─────────────       │  Тип: Гражданское  Стадия: Идёт       │
│  Дело 1             │  Цель / Краткое описание              │
│  Дело 2             │  Участники                            │
│  Дело 3             │  Материалы дела                       │
│                     │  [Тип ▾] [Группа ▾]                   │
│                     │  📄 документ.pdf  12 КБ  ✎ 🗑          │
│                     │  📷 фото.png      200 КБ ✎ 🗑          │
└─────────────────────┴───────────────────────────────────────┘
- Слева — список дел и фильтр (по стадии / типу судопроизводства).
- Справа — карточка дела: название, цель, описание, участники, материалы.
- Тулбар сверху — действия над делом.

### 3. Дело

Создание/редактирование:
- Название, краткое описание, цель.
- Тип судопроизводства (гражданское / уголовное / административное / арбитражное).
- Стадия (старт / идёт процесс / апелляция / кассация / завершено).
- Участники: имя, роль (истец / ответчик / третье лицо / судья / …), контакты, адрес, описание.

Материалы дела — любые файлы:
- 📄 Документы (pdf, docx, xlsx, txt, rtf, …)
- 📷 Фото (png, jpg, gif, bmp, webp, heic)
- 🎬 Видео (mp4, mov, avi, mkv, webm, …)
- 🎧 Аудио (mp3, wav, ogg, flac, m4a)
- 📦 Другое (архивы, бинарники, что угодно)

Тип определяется автоматически по расширению и magic bytes. Иконки в списке показывают категорию.

### 4. Работа с документом
| Действие | Как |
|----------|-----|
| Открыть | Клик по строке документа → предпросмотр (текст / картинка / fallback для остального) |
| Открыть в системе | В окне просмотра — кнопка «↗️ Открыть в системе» (для pdf, video, docx — запускается системное приложение) |
| Редактировать метаданные | Кнопка ✎ → отображаемое имя, группа, описание |
| Удалить | Кнопка 🗑 → удаляет и файл с диска, и из дела |

### 5. Группы документов
Каждое дело имеет свой справочник групп («Блок 1», «Приложения», «Переписка», «Доказательства», …).

- Создать — в редакторе документа: ввести название → «+ Создать группу».
- Назначить — выбрать в ComboBox группы → сохранить.
- Удалить — кнопка «🗑 Удалить группу» (документы останутся, но перейдут в «Без группы»).
- Фильтр — в главном окне, ComboBox «Группа».

### 6. Фильтры

- Дела слева: «Все дела / 🟡 Старт / 🟢 Идёт процесс / 🟠 Апелляция / … / 📘 Гражданские / 📕 Уголовные / …».
- Документы справа: тип (📄/📷/🎬/🎧/📦) + группа.

## Где хранятся данные

Всё — в папке **Документы/CaseManager/** (или ~/Documents/CaseManager на Linux/macOS).
'''
Документы/CaseManager/
└── <guid-дела>/                    # одна папка = одно дело
    ├── case.json.enc               # метаданные (AES-GCM)
    └── docs/                       # материалы дела
        ├── исковое-заявление.pdf
        ├── договор-аренды.docx
        ├── фото-места-происшествия.jpg
        └── ...
'''

- **case.json.enc** — зашифрованный JSON с названием, целью, участниками, списком документов, справочником групп.
- **docs/ — файлы документов как есть** (не шифруются — так удобно открывать их внешними программами).
- Порядок в папке: чтобы перенести дело на другой компьютер — скопируйте папку дела целиком. Имя case.json.enc не меняется.

> 💡 Если хотите шифровать и сами документы — это следующая итерация. Сейчас шифруются только метаданные.


## Безопасность

### Что защищено

- Метаданные дела (case.json.enc) — AES-256-GCM с ключом, производным от мастер-пароля через PBKDF2-SHA256 (200 000 итераций).
- Соль — уникальная для каждого файла, хранится в первых байтах.
- Nonce — уникальный на каждое шифрование.
- Тег аутентификации — ловит подмену файла (если кто-то изменит хоть байт — расшифровка упадёт с CryptographicException).

### Что не защищено (v1)
 Файлы документов в docs/ — хранятся как есть. Их можно открыть любым приложением. Если нужна полная защита — планируется в v2 (шифрование каждого файла .enc + временная расшифровка при просмотре).
- Имена файлов в docs/ — видны в проводнике.
- Мастер-пароль — не хранится, не восстанавливается. Если забыли — данные потеряны.

### Рекомендации

- Запишите мастер-пароль в надёжном месте (менеджер паролей, бумажный сейф).
- Резервная копия — копируйте всю папку CaseManager на внешний диск / в облако (например, раз в неделю).
- Не храните папку CaseManager в публичных облаках без шифрования (метаданные защищены, но файлы — нет).
